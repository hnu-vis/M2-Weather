# M2-Weather

## Dataset

The M3 station datasets used by M2-Weather are available at [rongwen/M2-Weather on Hugging Face](https://huggingface.co/datasets/rongwen/M2-Weather). Download `France.tar.gz`, `Europe.tar.gz`, or `Global.tar.gz` from the **Files and versions** tab. The dataset repository also includes documentation, extraction instructions, and the `SHA256SUMS` checksum file.
